# Python 对象模型笔记：名字是标签，对象是实物

> 适用：已掌握 Python 基础语法，正在建立"变量/对象/引用"心智模型的初学者。
> 配套真实代码：`pcm_host_tool.py`（串口上位机，状态机解析里大量用到这些概念）。

---

## 1. 核心模型：名字是标签，对象是实物

```python
a = 1
```

- **对象**（实物）：`1` 这个整数对象，**没有名字**；
- **标签**（名字）：`a` 只是贴在那个对象上的标签（官方叫"引用/绑定"）；
- 同一个对象可以被贴多个标签：

```python
a = 1
b = a      # 不是复制！b 也贴到同一个对象 1 上
```

- **对象没有名字**；名字只是入口。一个对象可以有很多名字，也可以一个名字都没有（无名对象会被自动回收）。

---

## 2. 等号：先算右边，再绑左边

```python
a = 1
a = a + 1   # 先算右边 a+1 = 2 → 再把标签 a 撕下来贴到 2 上
```

| 右边写法 | 对象从哪来 | 会不会新建 |
|---|---|---|
| `a = 1`、`a = "abc"` | 编译期常量（LOAD_CONST） | **不新建**，小整数 -5~256 还有缓存池，大家共用 |
| `a = [1,2,3]`、`a = MyClass()` | 运行时构造 | **每次新建**独立对象 |
| `a = b` | 取 b 指向的对象 | 不新建，贴同一个 |

要点：**写在 `=` 左边的名字才会被重新绑定**；右边的名字只是被"读取"。

---

## 3. 标签不能运算

- 没有 `p+1`、`&a`、`*p` 这类指针运算；
- `a + 1` 里的 `+` 是**对象在做加法**，标签只是被读取用来找到对象；
- 标签层面允许的操作只有：

```python
a = 1        # 绑定：贴标签
b = a        # 读取：顺着 a 找到对象，让 b 也贴上
del a        # 删除：撕掉标签（对象还在）
a is b       # 判断：两个标签是否贴同一个对象（最接近"指针比较"）
id(a)        # 查看对象地址（相当于 &a，但只是"看"，不能算）
```

---

## 4. 标签 ≠ C 指针

"共享、间接"这层理解用指针类比是对的，但把标签当"指针"会带出三个错误直觉：

| 维度 | C 指针 | Python 标签 |
|---|---|---|
| 本质 | 整数（内存地址） | 名字（绑定关系） |
| 运算 | `p+1`、`&x`、`*p` | 没有指针运算 |
| 类型 | `int*` 只能指 int | 可贴任意类型 |
| 取指向的值 | 要 `*p` 解引用 | 直接用名字就是值 |
| 修改对象 | `*p = 4` 真改内存 | int 不可变，只能换标签 |
| 空值 | `NULL` | `None`（也是个对象） |
| 多级 | `int**` | 无此概念 |

类比：**C 指针 = 门牌号**（能加 1、能打印、能解引用）；**Python 标签 = 人名**（不能"张三+1"）。

## 5. 重新绑定 vs 修改对象（经典坑）

```python
# 场景 A：撕标签（重新绑定）→ 不影响别人
a = 1
b = a
b = 4        # 只是 b 换对象贴；a 还是 1

# 场景 B：修改对象内部 → 所有标签都看到变化
x = [1, 2, 3]
y = x        # 贴同一个列表对象
y.append(4)  # 修改的是对象本身
print(x)     # [1, 2, 3, 4]  ← x 也变了！
```

| 代码 | 动作 | 结果 |
|---|---|---|
| `b = 4` | 撕标签（重新绑定） | 其他标签不受影响 |
| `y.append(4)` | 通过标签找到对象，修改对象内部 | 共享对象的所有标签都看到变化 |

想真复制一个可变对象：`y = x.copy()` 或 `y = x[:]`（显式新建对象）。

## 6. del：删除名字，不是释放内存

```python
del self.buf[:idx]   # 删列表一段（切片删除）
del self.buf[0]      # 删列表单个元素
del x                # 删变量（名字）
del d["key"]         # 删字典键
del obj.attr         # 删对象属性
```

**del 不是 C 的 free()**：

| | C 的 free() | Python 的 del |
|---|---|---|
| 干什么 | 手动释放内存 | 只删掉"名字"这个标签 |
| 内存谁管 | 程序员 | 引用计数 + 垃圾回收器（自动） |
| 写错后果 | 野指针、双重释放 | 几乎不可能出错 |

`del x` 只是让对象没人引用 → 引用数归 0 → GC 自动回收。你不需要、也不应该手动"释放"。

## 8. 函数名、类名也是标签

一切皆对象：函数对象、类对象和整数、列表一样，都是"实物"，名字都是标签。

```python
def greet():
    print("hi")

f = greet        # 标签 f 贴到同一个函数对象上
f()              # 输出 hi —— 标签叫什么无所谓

funcs = [greet, add]   # 函数能进列表（函数是对象的铁证）

class Dog:
    def bark(self):
        print("woof")

D = Dog          # 类标签也能复制
d = D()          # 用 D() 构造实例，和 Dog() 一样
```

**经典例子：第二次 def**：

```python
def greet():
    print("hi")

f = greet        # f 贴着"旧函数"

def greet():     # 又 def 一次 → 创建新函数对象，greet 换标签
    print("bye")

greet()          # bye（greet 现在指向新函数）
f()              # hi  ← f 还贴着旧函数对象
```

结论：`def`/`class` = 创建对象 + 绑定名字。

## 9. def / class：定义时造对象；调用时造实例

| 语句 | 执行时机 | 创建什么 | 谁的实例 | 什么时候"造新的" |
|---|---|---|---|---|
| `def greet:` | 执行到这一行 | 函数对象（1 个） | `function` 类的实例 | 定义时造一次，之后一直复用 |
| `greet()` | 调用时 | **不新建函数对象**；只新建"帧"执行函数体 | ——（帧是运行上下文，不是对象） | 函数对象从不重建；帧每次调用新建 |
| `class Dog:` | 执行到这一行 | 类对象（1 个） | `type` 类的实例 | 定义时造一次 |
| `Dog()` | 调用时 | 实例对象（每调 1 个） | `Dog` 类的实例 | **每次都新建**，互不干扰 |

```python
class Dog: ...      # 执行到这里 → 类对象 Dog 已经存在
d1 = Dog()          # 调用类 → 创建实例 1
d2 = Dog()          # 再调用 → 创建实例 2（和 d1 是俩独立对象）
```

类对象 = 蓝图（1 份）；实例对象 = 按蓝图盖的房子（N 份）。

## 10. 调用与返回值：`()` 产生对象，`=` 产生标签

```python
result = greet()
```

1. 通过标签 `greet` 找到函数对象；
2. `()` 执行函数体；
3. 函数体 `return` 出一个**结果对象**（没 return 就是 `None` 对象）；
4. `=` 把 `result` 标签贴到结果对象上。

```python
x = add          # ① 不带括号：x 贴【函数对象】→ x(1,2) 能调用
y = add(1, 2)    # ② 带括号：先运行 → y 贴【结果对象 3】→ y() 会报错
```

- 单独一行 `add(1, 2)`：结果对象没人贴标签 → 无名对象 → 立即被 GC 回收；
- **标签永远是 `=` 的活；`()` 只是"运行并产出对象"。**

## 11. 自测题（先自己做，再看答案）

```python
# 1.
a = 1
b = a
b = 4
a = ?                    # 答案：1（b 换标签，a 不动）

# 2.
a = 1
b = a
b = a + 1
a = ?                    # 答案：1（a 只被读值，不被绑定）

# 3.
x = [1, 2, 3]
y = x
y.append(4)
x = ?                    # 答案：[1, 2, 3, 4]（y 改了共享对象本身）

# 4.
def f():
    return 10
g = f
h = f()
g() = ?                  # 答案：10（g 是函数，调用后返回 10）
h   = ?                  # 答案：10（h 直接贴结果对象）
# g 和 h 能一样吗？      # 不一样：g 是函数对象，h 是整数对象

# 5.
def greet():
    return "A"
f = greet
def greet():
    return "B"
f() = ?                  # 答案："A"（f 还贴着旧函数对象）
greet() = ?              # 答案："B"（greet 换到新函数）
```

## 12. 创建函数对象的 4 种方式（不止 def，补上 lambda）

前面说过 "def / class = 创建对象 + 绑定名字"，但 `def` 只是最常见的一种，不是唯一。函数对象还有别的方式能造出来——正好把第 7 节关键字表里没展开的 `lambda` 补上。

### 方式 1：def（最常见）

```python
def add(a, b):
    return a + b
```

### 方式 2：lambda（匿名函数）—— 关键新概念

```python
add2 = lambda a, b: a + b     # 一行造一个函数对象，贴标签 add2
add2(1, 2)                    # 3
```

### 方式 3：函数工厂（一个函数返回另一个函数）

```python
def make_multiplier(n):
    def inner(x):             # 里面还是用 def 造
        return x * n
    return inner              # 返回函数对象

times3 = make_multiplier(3)   # times3 就是一个函数对象
times3(5)                     # 15
```

### 方式 4：从已有函数的代码"克隆"（高级，证明函数是对象）

```python
import types

def original(x):
    return x + 1

clone = types.FunctionType(original.__code__, {})   # 用代码对象克隆
clone(10)                     # 11
```

> 注意：克隆时要传 globals 字典；空 `{}` 只够没有全局依赖的函数用。

### lambda 是什么：没有名字的函数

```python
f = lambda x: x * 2
#   └─┬─┘ └─┬──┘
#   参数   返回值（只能一个表达式）
```

- `def` 是**语句**：完整定义，能写多行；
- `lambda` 是**表达式**：有值，能出现在任何表达式位置；
- 所以它经常"临时造、用完即弃"，比如排序时指定比较键：

```python
data = [("b", 2), ("a", 3), ("c", 1)]
sorted(data, key=lambda item: item[1])   # 按第 2 个元素排
# 结果 [("c",1), ("b",2), ("a",3)]
```

方式 3 里 `make_multiplier(3)` 返回的 `inner`，本质也是 `def` 造的——所有方式最终都通向"函数对象"。

### 一句话对比

| 方式 | 写法 | 特点 |
|---|---|---|
| `def` | 语句 | 完整、多行、有名字 |
| `lambda` | 表达式 | 单行、匿名、临时 |
| 函数工厂 | `return` 出函数 | 批量"定制"函数（闭包） |
| `types.FunctionType` | 克隆 `__code__` | 高级玩法，证明函数是对象 |

## 附：一句话口诀

> **一切皆对象，名字皆标签。** 等号先算右、再绑左；`()` 产出对象、`=` 才造标签；重新绑定撕标签，改对象内部则人人可见；del 删名字不释放内存；def/class 定义时造对象，调用时（实例）才新建。
