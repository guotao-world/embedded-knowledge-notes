# 设备树解析流程

**注意：**

-   **/sys 和 /proc 都只是"展示"，真正被驱动使用的是内核已经展开好的 device_node 树**
-   **mx_pinctrl_parse_groups() 它解析的是struct device_node（内核内存中的设备树结构）**
-   **/sys/firmware/devicetree 和 /proc/device-tree 只是 device tree 的调试/兼容"视图层"，不是核心机制，可以在内核配置中关闭，但不能理解为可随意删除的运行时组件。**
-   **unflatten_device_tree()完全不依赖任何驱动（包括SoC适配驱动）。它做的事情是：纯数据结构构建，不涉及硬件语义。本质就是把 DTB（二进制设备树）解析成内核的 device_node 树结构。**
