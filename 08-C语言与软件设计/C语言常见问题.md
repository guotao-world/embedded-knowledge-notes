# C 语言常见问题

## Q: malloc 后返回了一个 ptr 指针，释放的时候只需要 free(ptr) 就可以了，那么 free(ptr + 1) 会怎么样？

**A：** 直接使用 `free(ptr + 1)` 会导致**未定义行为（Undefined Behavior）**，这几乎总是意味着程序会崩溃（如段错误）或发生难以调试的内存损坏。

### 情况一：ptr + 1 仍然指向同一块申请的内存内部

这是最常见的情况，比如你申请了一个数组，然后指针偏移了一个元素。

**后果：** `free` 会试图在你传入的地址（ptr+1）的前方查找"头"信息。然而，那里存放的是你的**有效数据**，而不是正确的内存管理元数据。`free` 会将这些数据误认为是头信息并加以解析，这必然会导致混乱，最常见的后果就是**段错误（Segmentation Fault）**，程序立即崩溃。

### 情况二：ptr + 1 指向了完全无关的内存区域（如栈上变量或常量区）

如果 ptr+1 指向了一个栈变量或者字符串常量，情况会更糟。

**后果：** `free` 会尝试从那个完全无关的地址往前查找"头"信息，这几乎肯定会破坏堆的内存管理结构。这会导致**堆内存损坏（Heap Corruption）**。程序可能不会立即崩溃，但在后续的 `malloc` 或 `free` 操作中会出现各种离奇错误，这种错误极难定位。
