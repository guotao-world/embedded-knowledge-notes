# linux 用户态内核态

## 一、用户态进入内核态的两种情况

| 类型 | 触发方式 | 特点 |
|------|---------|------|
| **中断** | 硬件触发 | 被动的 |
| **陷入** | 异常或软件触发 | 主动的 |

三种具体方式：**中断、异常、系统调用**。

---

## 二、异常

异常是 CPU 硬件逻辑发现问题后自动触发。如缺页异常，CPU 识别到了错误程序操作而产生的触发动作。

```
程序犯错 → CPU 发现 → CPU 触发异常（trap）
```

---

## 三、系统调用

用户态程序通过 `svc`（ARM）或 `syscall`（x86_64）指令主动陷入内核态，请求内核提供服务（如 open、read、write、mmap 等）。

---

## 四、对比总结

| 方式 | 触发源 | 主动性 | 典型场景 |
|------|--------|--------|---------|
| 中断 | 硬件外设 | 被动 | 按键、DMA 完成、网络数据包 |
| 异常 | CPU 硬件检测 | 被动 | 缺页、非法指令、数据访问错误 |
| 系统调用 | 用户程序指令 | 主动 | 文件操作、内存映射、进程管理 |
